# Achievement Lab

This public repository is a transparent, short-lived test of GitHub achievement triggers.

- **Quickdraw**: open an issue and close it within 5 minutes.
- **YOLO**: merge a pull request without a review (admin bypass of a required-review rule).

The repository is kept public for about 48 hours so GitHub's asynchronous achievement
processor can index the events, then it is deleted.

No production code lives here.
